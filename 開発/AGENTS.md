# 開発領域

この下位領域は、プロダクトをどう変更・検証し、リポジトリの情報をどう保つかを管理します。

- 日常の判断原則: `開発原則.md`
- 最上位ディレクトリ・命名・責務配置: `構成規約.md`
- 哲学・定義・要求・設計の責務関係: `判断構造.md`
- AI向け情報の案内: `AIネイティブ原則.md`
- AIから必要情報へ辿れるかの監査: `AI検索監査.md`
- 開発時に意味を揃える語: `用語.md`
- Issueの成果型・実行許可・人手待ち・依存関係: `Issue運用.md`
- PR・コミット・継続作業: `作業管理.md`
- 決定的検証と内容を読む監査の境界: `検証.md`
- 哲学・原則・方針・規約を変更する: `用語.md` と `../skills/principle-change/SKILL.md`
