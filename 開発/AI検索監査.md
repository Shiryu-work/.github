# AI検索監査

過去会話を知らないAIが、現在の依頼から必要な管理元へ短く到達できるかを確認します。

- `AGENTS.md` が階層案内として機能し、親の説明や詳細本文を複製していないか
- 同じ値・関係・定義・要求・設計に複数の管理元がないか
- 現在使っているパスから旧パス・移行中パスへ誘導していないか
- 安定した対象をパス、見出し、ID等で直接参照できるか
- プロダクトの目的・要求を知るために過去Issue / PR / チャットを必須にしていないか
- コード・スキーマ・データ・設定から確認できる内容を、生成要約や古い記録へ依存していないか
- 変更対象と無関係な大量の情報を常時読ませていないか

問題がある場合は、第二の索引を増やす前に管理元、命名、AGENTSの案内、直接参照を修正します。
