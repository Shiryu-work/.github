# 判断基準の変更

上位文書や `AGENTS.md` を肥大化させず、必要な判断だけを適切な場所へ置くための手順です。

## 入力

- 追加・変更したい判断
- その判断が必要になった依頼、失敗、反復、または利用者の明示判断
- 変更対象に最も近い `AGENTS.md`
- 関係する既存の哲学・原則・方針・規約・手順

## 手順

1. 一般的なAIの挙動や開発上の常識として既に期待でき、この記述がなくても成果が変わらないなら追加しない。
2. その判断が、入力にある依頼・失敗・反復・利用者の明示判断のいずれにも結び付かない一般論なら追加しない。
3. 現在の用語定義に従い、哲学・原則・方針・規約・手順のどこに置くか決める。
4. 同じ意味の管理元があれば新設せず、そこを修正する。
5. 最も近い責務へ置く。ルート `AGENTS.md` へ置くのは、ほぼ全作業で常時必要なものだけにする。
6. 哲学は大切にする性質を短い語句で置く。義務、禁止、例外、適用範囲、操作手順は下位へ置く。
7. 変更によって古くなった参照・用語・重複記述を同じ変更で直す。
